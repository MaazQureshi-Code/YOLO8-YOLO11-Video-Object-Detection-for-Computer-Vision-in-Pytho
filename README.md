YOLOv8 Vehicle Detection from Video

This project uses YOLO and Python to perform real-time vehicle detection from video files. The model analyzes each frame of the uploaded video and detects vehicles such as cars, trucks, buses, and motorcycles using computer vision techniques.

Features
Vehicle detection from prerecorded video
Detection of cars, trucks, buses, and motorcycles
Bounding boxes with confidence scores
Real-time frame processing using YOLOv8
Video-based computer vision application
Simple and efficient Python implementation
